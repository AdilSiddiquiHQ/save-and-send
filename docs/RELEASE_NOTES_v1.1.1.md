A one-line fix on top of 1.1.0: the selected language chip in Settings drew its
label at the top of the chip instead of centring it, so "English" sat visibly
higher than اردو, हिन्दी, العربية, and বাংলা beside it.

Nothing else changed. The download pipeline, the translations, and the layouts
are identical to 1.1.0.

## Install

1. Download `SaveAndSend-v1.1.1-arm64.apk`.
2. Optionally verify the SHA-256 checksum.
3. Install over 1.1.0. If you installed an older build signed with a different
   key, uninstall it first.
